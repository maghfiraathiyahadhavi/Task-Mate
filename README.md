# TaskMate - To-Do List Website

Aplikasi latihan React untuk praktikum tanpa login, akun, email, password, database, atau backend.

## Fitur
- Dashboard ringkasan tugas
- Tambah, lihat, edit, dan hapus tugas (CRUD)
- Tandai tugas selesai
- Pencarian dan filter status
- Halaman 404 Not Found untuk URL yang tidak terdaftar
- React Router, Props, PropTypes, useState, useEffect, dan Lucide Icons
- Penyimpanan tugas menggunakan localStorage

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `taskmate` di VS Code.
3. Buka terminal pada folder proyek.
4. Jalankan `npm install`.
5. Jalankan `npm run dev`.
6. Buka alamat lokal yang muncul di terminal (umumnya http://localhost:5173).

Aplikasi langsung membuka Dashboard. Data tugas tersimpan di localStorage browser.
